# Historical Phase 1 plan (non-authoritative)

ให้ใช้เอกสารต่อไปนี้แทน:

- [CONTEXT.md](CONTEXT.md) — glossary และ domain rules
- [architecture-refactor-spec.md](docs/architecture-refactor-spec.md) — current architecture/spec
- [architecture-refactor-tickets.md](docs/architecture-refactor-tickets.md) — GitHub issue tracker และ dependency graph
- [ADRs](docs/adr/) — accepted decisions
