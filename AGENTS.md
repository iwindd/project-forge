## Agent skills

### Issue tracker

Issues for this repo live in GitHub Issues for `iwindd/project-forge`; use the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repo. Read the root `CONTEXT.md` and relevant ADRs in `docs/adr/`. See `docs/agents/domain.md`.

## Product UI priority

- Design and verify the Admin UI for the iPad Air 10.5-inch first, in both landscape and portrait orientations.
- Treat tablet touch targets, orientation changes, available vertical space, and sidebar collapse as primary acceptance criteria.
- Do not optimize primarily for desktop or mobile until the iPad layouts are working well.
